5. Supervisor de planta.
Momento en que se calculan
Históricos, estimados, estándar.
Ejemplos:
1. Factura pasada
2. Nómina anterior
3. Presupuesto próximo
4. Costos por estudios
5. Proyección de energía.
Momento frente ingresos
Costo del producto/período.
Ejemplos:
1. Harina (producto)
2. Empaque (producto)
3. Renta oficina (período)
4. Publicidad (período)
5. Papelería (período).
Control sobre el costo
Controlables vs no controlables.
Ejemplos:
1. Negociación materia prima
2. Horas extra
3. Tarifas eléctricas
4. Depreciación contable
5. Impuestos.
Comportamiento
Fijos, variables, mixtos.
Ejemplos:
1. Alquiler local (fijo)
2. Agua/producción (variable)
3. Comisiones de venta
4. Sueldo base + bono
5. Mantenimiento mensual.
Importancia en decisiones
Relevantes, irrelevantes, hundidos, oportunidad.
Ejemplos:
1. Gasto extra pedido especial
2. Proveedor alternativo
3. Maquinaria depreciada
4. Material ya usado
5. Ahorro por decisión.
Tipo de sacrificio
Desembolsados o de oportunidad.
Ejemplos:
1. Pago materia prima
2. Nómina
3. No alquilar local
4. Empleados en proyecto menos rentable
5. Uso de capital propio.
Cambio por actividad
Incremental, decremental.
Ejemplos:
1. Insumo extra lote
2. Contrato temporal
3. Ampliación turno
4. Reducción almacén
5. Menor producción.
Relación ante disminución
Evitable/inevitable.
Ejemplos:
1. Operador eventual
2. Campaña producto cerrado
3. Seguridad área cerrada
4. Renta local vigente
5. Impuestos sobre inmueble.
Impacto en calidad
Prevención, evaluación, fallas.
Ejemplos:
1. Manual procesos
2. Capacitación ISO
3. Auditoría
4. Inspección producto
5. Retrabajo defectos.
